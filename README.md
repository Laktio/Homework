# Проект "Виджет банковских операций клиента"
## Описание
Проект "Виджет банковских операций клиента" это приложение для визуализации 
банковских операций. Приложение принимает на вход номера счетов и банковских карт
и выводит их замаскированные версии. Приложение принимает информацию по 
банковским операциям и сортирует их по требуемым параметрам. Приложение принимает 
информацию по транзакциям и выводит поэтапно транзакции с соответствующим типом валюты 
операции

## Использование
1. подавать на вход номера счетов и карт и получать замаскированные версии
2. подавать на вход информацию по операциям по клиентам и получать отсортированные списки данных
3. подавать на вход информацию по транзакциям и получать поэтапно транзакции с соответствующим 
типом валюты операции
4. подавать на вход информацию по транзакциям и получать поэтапно описание операции
5. реализован декоратор для логирования корректности работы функций в файл melog.txt если 
указан в параметрах декоратора или в консоль если не указан
